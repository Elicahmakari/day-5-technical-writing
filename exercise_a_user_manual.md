## Setting Up a GitHub Repository and Making a First Commit

### 1. Introduction

This procedure explains how a beginner can create a GitHub repository, add a project file and make the first commit.

GitHub is an online platform used by developers to store, manage and collaborate on software projects.

### 2. Prerequisites

Before starting, ensure you have:

1. A computer with internet access.
2. A web browser such as Google Chrome or Firefox.
3. A valid email address.
4. A GitHub account.
5. Basic knowledge of creating and saving files.
6. A project file to upload, such as README.md.

### 3. Step-by-Step Procedure

**Step 1: Open GitHub**

Action: Open your web browser and visit https://github.com.

Expected result: The GitHub homepage appears.

**Step 2: Sign in to your account**

Action: Click Sign in and enter your GitHub username and password.

Expected result: Your GitHub dashboard opens.

**Step 3: Start creating a repository**

Action: Click the plus (+) icon in the top-right corner and select New repository.

Expected result: The repository creation page appears.

**Step 4: Enter the repository name**

Action: Type `my-first-project` in the Repository name field.

Expected result: The repository name appears in the field.

**Step 5: Add a description**

Action: Enter a short description explaining your project.

Expected result: The description appears below the repository name.

**Step 6: Select repository visibility**

Action: Select Public.

Expected result: The repository is configured to be publicly accessible.

**Step 7: Initialize the repository**

Action: Select the Add a README file checkbox.

Expected result: GitHub is configured to create a README file.

**Step 8: Create the repository**

Action: Click Create repository.

Expected result: Your new repository opens and displays the README file.

**Step 9: Create a project file**

Action: Click Add file, select Create new file and enter `hello.py`.

Expected result: The GitHub file editor opens.

**Step 10: Enter Python code**

Action: Type the following code into the editor:

```python
print("Hello, World!")
```

Expected result: The Python code appears in the editor.

**Step 11: Commit the file**

Action: Click Commit changes, enter the message `Add first Python program` and confirm the commit.

Expected result: The file is saved and the commit is recorded.

**Step 12: Verify the repository**

Action: Open the repository's main page.

Expected result: The README.md and hello.py files are visible.

### 5. Troubleshooting

**Problem: Repository name already exists.**

This happens when a repository with the same name already exists under your GitHub account.

**Solution:**

1. Choose a different repository name.
2. Check whether you already created a repository with that name.
3. Avoid spaces and unsupported characters in repository names.

### 6. Conclusion

Creating a GitHub repository and making a first commit is an important skill for software developers. GitHub helps developers organize projects, track changes and collaborate with others.

Following these steps allows beginners to create and manage their first software project successfully.
